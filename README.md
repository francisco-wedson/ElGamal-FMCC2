## 📌 Descrição do Projeto

Este projeto consiste na implementação do algoritmo de criptografia de chave pública baseado no modelo proposto por Taher ElGamal em 1985.

O sistema baseia-se na dificuldade do problema do logaritmo discreto em grupos de inteiros módulo um número primo grande, além de utilizar conceitos do protocolo Diffie-Hellman.

Também é realizada uma comparação entre o ElGamal e outros sistemas criptográficos de chave pública, como o RSA.
